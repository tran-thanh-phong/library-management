# 2.7.1 Báo Cáo Tổng Quan (Dashboard Overview)

## Thông tin chung
- **Actor:** Quản lý viên, Nhân viên thư viện
- **Yêu cầu:** Đăng nhập vào hệ thống với vai trò quản lý viên hoặc nhân viên thư viện, có dữ liệu sách, mượn, trả
- **Mô tả:** Hiển thị tổng quan các thống kê quan trọng của hệ thống

## Luồng chính

```mermaid
flowchart TD
    Start([Bắt đầu]) --> CheckAuth{Đã đăng nhập?}
    
    CheckAuth -->|Không| RedirectLogin[Chuyển hướng đến<br/>trang đăng nhập]
    CheckAuth -->|Có| CheckRole{Vai trò?}
    
    RedirectLogin --> End([Kết thúc])
    
    CheckRole -->|Độc giả| RedirectReader[Chuyển hướng đến<br/>dashboard độc giả]
    CheckRole -->|Nhân viên/Quản lý| LoadDashboard[Tải dashboard]
    
    RedirectReader --> End
    
    LoadDashboard --> FetchStats[Tải các thống kê:<br/>- Tổng số sách<br/>- Tổng số độc giả<br/>- Tổng đơn mượn hôm nay<br/>- Top 5 sách phổ biến<br/>- Danh sách độc giả nợ quá hạn]
    
    FetchStats --> CalculateBooks[ Tính toán số sách:<br/>- Có sẵn<br/>- Đang mượn<br/>- Bị mất<br/>- Hư hỏng]
    
    CalculateBooks --> CalculateReaders[ Tính toán số độc giả:<br/>- Hoạt động<br/>- Vô hiệu hóa]
    
    CalculateReaders --> CalculateTodayBorrows[ Tính đơn mượn hôm nay]
    
    CalculateTodayBorrows --> GetTopBooks[ Lấy Top 5 sách phổ biến nhất]
    
    GetTopBooks --> GetOverdueReaders[ Lấy danh sách độc giả nợ quá hạn]
    
    GetOverdueReaders --> DisplayDashboard[Hiển thị dashboard với:<br/>- Cards thống kê<br/>- Biểu đồ<br/>- Bảng dữ liệu]
    
    DisplayDashboard --> End
```

## Luồng tính toán thống kê sách

```mermaid
flowchart TD
    Start([Bắt đầu]) --> QueryBooks[Truy vấn database<br/>lấy thông tin sách]

    CalculateTotal --> DisplayStats[Hiển thị thống kê:<br/>- Có sẵn: X<br/>- Đang mượn: Y<br/>- Bị mất: Z<br/>- Hư hỏng: W<br/>- Tổng: T]
    DisplayStats --> End([Kết thúc])
```

## Luồng tính toán thống kê độc giả

```mermaid
flowchart TD
```

## Luồng thay thế

### Luồng 1: Người dùng chưa đăng nhập
- Hệ thống chuyển hướng đến trang đăng nhập

### Luồng 2: Người dùng là độc giả
- Hệ thống chuyển hướng đến dashboard độc giả (không có tính năng này)

### Luồng 3: Chưa có dữ liệu
- Hiển thị 0 cho tất cả các thống kê
- Hiển thị thông báo "Chưa có dữ liệu" cho các phần không có dữ liệu

### Luồng 4: Lỗi tải dữ liệu
- Hiển thị thông báo lỗi và nút "Thử lại"
- Cho phép người dùng tải lại dashboard

## Xử lý lỗi

```mermaid
flowchart TD
    Error([Lỗi xảy ra]) --> CheckErrorType{Loại lỗi?}
    
    CheckErrorType -->|Lỗi tải dữ liệu| ShowLoadError[Hiển thị lỗi:<br/>Không thể tải dữ liệu dashboard.<br/>Vui lòng thử lại]
    CheckErrorType -->|Lỗi tính toán| ShowCalcError[Hiển thị lỗi:<br/>Lỗi tính toán thống kê]
    CheckErrorType -->|Lỗi hệ thống| ShowSystemError[Hiển thị lỗi:<br/>Đã xảy ra lỗi hệ thống.<br/>Vui lòng thử lại sau]
    
    ShowLoadError --> AllowRetry[Hiển thị nút Thử lại]
    ShowCalcError --> AllowRetry
    ShowSystemError --> AllowRetry
    AllowRetry --> ClickRetry{Click Thử lại?}
    ClickRetry -->|Có| Reload[Tải lại dashboard]
    ClickRetry -->|Không| EndError([Kết thúc với lỗi])
    Reload --> EndError
```

## Thông tin hiển thị

### Cards thống kê:

#### Tổng số sách:
- Có sẵn: X
- Đang mượn: Y
- Bị mất: Z
- Hư hỏng: W
- Tổng: T

#### Tổng số độc giả:
- Hoạt động: X
- Vô hiệu hóa: Y
- Tổng: X + Y

#### Tổng đơn mượn hôm nay:
- Số đơn mượn được tạo hôm nay

### Top 5 sách phổ biến nhất:
- Bảng hoặc danh sách hiển thị:
  - Tên sách
  - Tác giả
  - Số lần mượn
  - Có thể sắp xếp theo số lần mượn

### Danh sách độc giả nợ quá hạn:
- Bảng hiển thị:
  - Tên độc giả
  - Email
  - Số sách quá hạn
  - Có thể click để xem chi tiết

## Chi tiết kỹ thuật

### Tính toán số sách:
```sql
SELECT 
  SUM(available_quantity) as available,
  SUM(borrowed_quantity) as borrowed,
  COUNT(CASE WHEN status = 'Mất' THEN 1 END) as lost,
  COUNT(CASE WHEN status = 'Hư hỏng' THEN 1 END) as damaged,
  SUM(total_quantity) as total
FROM books
```

### Tính toán số độc giả:
```sql
SELECT 
  COUNT(CASE WHEN status = 'Kích hoạt' THEN 1 END) as active,
  COUNT(CASE WHEN status = 'Vô hiệu hóa' THEN 1 END) as disabled,
  COUNT(*) as total
FROM users
WHERE role = 'Reader'
```

### Đếm đơn mượn hôm nay:
```sql
SELECT COUNT(*) 
FROM borrows
WHERE DATE(created_at) = CURRENT_DATE
```

### Top 5 sách phổ biến:
```sql
SELECT 
  b.id,
  b.title,
  b.author,
  COUNT(br.id) as borrow_count
FROM books b
JOIN borrows br ON b.id = br.book_id
GROUP BY b.id, b.title, b.author
ORDER BY borrow_count DESC
LIMIT 5
```

### Độc giả nợ quá hạn:
```sql
SELECT 
  u.id,
  u.name,
  u.email,
  COUNT(br.id) as overdue_count
FROM users u
JOIN borrows br ON u.id = br.reader_id
WHERE br.status = 'Quá hạn'
  AND br.due_date < NOW()
GROUP BY u.id, u.name, u.email
ORDER BY overdue_count DESC
```
